# Bill Splitter

A beginner-friendly Python program that divides a bill equally among multiple people and optionally adds a tip.

## Features
- Enter total bill amount
- Enter number of people
- Add a tip percentage
- Calculate final bill
- Calculate amount per person
- Basic input validation

## Formula
Tip = Total Bill × Tip % / 100

Final Bill = Total Bill + Tip

Amount Per Person = Final Bill / Number of People

## How to Run
```bash
python bill_splitter.py
```
